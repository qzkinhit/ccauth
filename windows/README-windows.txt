ccauth for Windows

ccauth-gui.exe   Window app. Keep it in the same folder as ccauth.exe.
ccauth.exe       Command line. Run "ccauth.exe help" for the commands.

Available on Windows
  - Claude Code accounts (save, switch, remove)
  - Gemini CLI accounts
  - Relay management and balances (ccauth agy add / quota)
  - Daily check-in, scheduled at 00:10 and 12:10 through Task Scheduler

macOS only
  - Antigravity third-party mode
  - Codex routing

Saved accounts, keys and passwords stay in %USERPROFILE%\.ccauth on this computer.
Windows may show a SmartScreen warning because the program is not signed:
choose "More info" and then "Run anyway".

ccauth Windows 版

ccauth-gui.exe   窗口程序，需要和 ccauth.exe 放在同一个文件夹。
ccauth.exe       命令行程序，运行 "ccauth.exe help" 查看命令。

Windows 上可用
  - Claude Code 多账号（保存、切换、删除）
  - Gemini CLI 多账号
  - 中转站管理与余额查询（ccauth agy add / quota）
  - 每日签到，通过任务计划程序在 00:10 与 12:10 自动执行

仅 macOS
  - Antigravity 第三方模式
  - Codex 分流

保存的账号、key 与密码只存在本机 %USERPROFILE%\.ccauth 目录。
程序没有签名，Windows 可能弹出 SmartScreen 提示，点「更多信息」再点「仍要运行」。
